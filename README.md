# Lumera

Lumera is an evolving ecosystem exploring the simulation of natural systems in modern C++ and SFML, inspired by *The Nature of Code.*

This is a playground where ideas from the book become part of a strange and magical world. It is a place where my imagination and technical skills can flourish as I explore what is possible.

Lumera will evolve as I explore motion, forces, particle systems, autonomous agents, evolution, neural networks, and other computational models of nature. A special focus is on emergent systems, procedural generation, and artificial life.

## Built With

* Modern C++
* SFML
* CMake

## Status

Lumera is an active learning project and experimental playground.
